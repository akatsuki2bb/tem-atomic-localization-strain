## PhD application description

I developed a five-fold benchmark comparing AtomSegNet, U-Net++, HRNet, and SwinUNet on 14,364 simulated HAADF-TEM images. The project links denoising and atomic-column segmentation to sub-pixel localization and exploratory lattice/strain analysis, showing that the model with the best image reconstruction is not necessarily the best for quantitative atomic measurements.
