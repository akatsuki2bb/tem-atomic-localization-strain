# Current benchmark tables

These files are the current quantitative snapshot generated by `notebooks/03_benchmark_and_physics.ipynb` on 14 September 2026.

## Primary sources

- `benchmark_summary.csv`: one row per architecture-condition group; use this for headline values.
- `benchmark_master.csv`: per-fold metrics and the exact checkpoint inventory used during evaluation.
- `n2v_contrast.json`: paired N2V-versus-direct IoU effects for the three CNN architectures.
- `checkpoint_inventory.csv`: the 35 discovered checkpoints. Paths are historical local paths and are not portable.

## Supporting analyses

- `subpixel_precision.csv` and `detector_floor.csv`: controlled fractional-shift experiment.
- `localization_report.csv` and `centroid_metrics.csv`: atomic-center and spacing diagnostics.
- `physics_all_frames.csv` and `strain_reference_space.csv`: lattice and exploratory strain outputs.
- `input_ablation.csv`: input-variant sensitivity.
- `ckpt_keys/`: state-dictionary key inventories used to verify architecture compatibility.

## Scope warning

The benchmark table uses five folds but only 600 validation images per fold. Downstream analyses use smaller selected subsets. Columns expressed in angstroms or picometres use an unverified historical scale and should not be quoted; prefer pixel units.
